- [ ] Use shared pure action/reducer helpers in the existing questionnaire refinement adapter and a read-only employee draft consumer; do not rewrite all five retail mode state machines.

- [ ] Employee feedback requires confirmation before changing a stated fact/essential. Inference can propose a change but cannot turn charging:none into either or silently remove an essential; unknown is not indifference.
- [ ] An employee draft change recomputes from the complete authorised candidate input, supports no-match/unavailable-data outcomes and rejects stale expected versions without applying a partial change. Inputs remain immutable and the caller explicitly receives the next draft version.
- [ ] Browse/draft undo is reversible within its local scope. Offer decline, expiry and acceptance are distinct future domain operations; this capability cannot release/restore a real hold or claim durable account learning.
- [ ] Update shared-kit catalogue/gallery examples for changed controls, showing visible scope and an undo outcome; use existing retail controls/tokens and the employee draft fixture without creating a new employee application screen.
