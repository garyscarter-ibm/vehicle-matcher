Valid flat metadata therefore reaches Angular but yields no vehicle.

  Immutable source trace: `Vehicles:105-137` validates and retains VehicleSnapshot display beside typed facts; `Evaluation:408` and `BuddyCandidates:179` retain that snapshot in the quote. `BuddyOfferConversion:361-368` and `RemoteSelectionConversion:117-122` copy the full accepted quote but pass only `quote.snapshot.facts` as stockFacts. `OrderingService:283-287` persists both full quote and stock facts in the existing immutable selection. Consequently, simply exposing the saved stock object is insufficient for this source layout: the supplied name/photo are in the immutable quote snapshot display. A narrow read projection can use that exact saved selected snapshot to supply the established display shape, with appropriate order identity checks and an allowlist; it need not expose the full quote, employee facts or unrelated stock, rewrite historical selections, add a store or migrate schema. This is the proposed repair boundary, not a completed repair. Genuine missing display must remain missing.
