actual_behaviour: The current reader resolves only employees.renewalId or the employee's default entitlement slot renewal (cases/index.js:51-58). FUCQ-116's two-slot regression at 53f86b409c85236b7891ec940e76ac61a1c66725 already checks that a B exception must not open an A case; absence of an A case does not prove the B event was handled.
