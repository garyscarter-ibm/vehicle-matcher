goal:
  **Requested by Gary Carter on 8 Nov 2026.** Today the manual and buddy order confirmations use the car's 7-digit stock order number as the "order reference" (HLD Q19), so there's no order id of its own. Gary decided each order should have a separate generated reference.

  **Acceptance:**

  * When an order is created through FUCQ-71's ordering authority, it gets a server-generated reference such as `GCSP-000123`. The reference is unique per run, stable across retries and reloads (idempotent), and stored on the order record. The format is recorded as a policy assumption.
  * The reference appears on the manual order confirmation and Print, the buddy handoff confirmation, the account order card (FUCQ-215 item 2), order progress and order history. The car's order number stays visible as the car's own fact, labelled as such.
  * Orders created before this change fall back to showing the car order number, labelled as such. No reference is invented for them.
  * Tests cover idempotent generation, a lost-response retry (no second reference), and display on every screen listed above.
  * No change to the ordering adapter's external contract unless it's needed. Report it if it is.

  **Risk:** this touches the ordering path (FUCQ-71, 108), so keep the diff small and run gcsp-critical-path.
