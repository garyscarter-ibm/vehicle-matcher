goal: As the presenter, I want a reproducible synthetic cohort, stock and release schedule built from declared assumptions, so that both routes in the comparison start from identical inputs that anyone can inspect.
acceptance:
- [x] **Pure, seeded generator:** `generateComparisonInputs(seed, policy)` returns the employees, the stock and the release schedule for one seed. The same seed, policy version and generator version give identical output; a different seed gives different output. It reads no clock, network or global random source.
- [x] **Employees:** the cohort size comes from a PolicyService key (default 1,000). Each employee has:
  a fictional ID, with no real names, contact details or licence data;
  a grade and points allowance drawn from keyed grade distributions;
  a renewal date inside the keyed horizon;
  underlying needs: essentials, and preference values each with its importance weight;
  a stated brief derived from those needs, with keyed brief-accuracy noise;
  an access group, with keyed access-time and response-time distributions;
  buddy participation, drawn from the keyed uptake rate.
- [x] **Stock and releases:** cars per employee, the model-line mix and the release cadence come from keys. Each car carries a synthetic `orderUuid` and a target-format `configurationId` (Q13). Configurations come through the vehicle corpus read port, or a reviewed fixture configuration set until the corpus is published. Nothing is written to the live run's stock.
- [x] **Keys, not literals:** every value above is a `comparison.*` key in FUCQ-82's seed, with value, unit, `assumed` status, a short basis, and source and date (build rules). The key list is recorded in `docs/gcsp/shared-contracts.md`. The generator holds no defaults of its own.
- [x] **What-if overlay:** the generator accepts an explicit alternative-policy overlay (for example a different order mix or points). An overlay is never published to PolicyService, and the output records it.
- [x] **Manifest:** each output carries the seed, policy version, overlay hash and generator version. The default seed list is a key (`comparison.seeds`).
