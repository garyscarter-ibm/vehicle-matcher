     - Cause: `GregPolicyResource.now()` (line 136) and `PolicyPublisher` (line 68) each read `PolicyClock`, and the deployed bean is `WallPolicyClock`. `GregPolicyProjection.changesFor` needs `effectiveFrom <= now` from the first read, and `PolicyPublication.prepareSuccessor` (line 124) needs `from >= now` from the second, later read.      - Node: reads the run clock, which is frozen between presenter ticks, so it accepts.
     - Related: Java preview `asOf` is likewise the resource clock, not the run clock.
