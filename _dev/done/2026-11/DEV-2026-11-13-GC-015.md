- journal API (for FUCQ-423): a committing `transaction`/`resetRun` returns `{ commit: true, outcome, mutations }` to its backend. `mutations` is a frozen array in first-write order, one entry per changed row identity: `{ type: 'insert'|'update', table, key (complete PK incl. runId), row (final stored row), expectedVersion (updates only: version stored before the tx) }`. Insert-then-CAS of one row stays one `insert` with the final row. Uncommitted attempts return no journal. `createMutationJournal()` and the optional `journal` arg of `createTransaction` are exported from core.js. Contract note in server/gcsp/repository/README.md.
