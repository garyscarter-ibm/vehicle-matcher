  On 8 Nov, gcsp-api's build of commit 9fcfcb23 succeeded at 13:00. The redeploy of the same commit after the change to the Standard plan then failed with `{"status":"artifact-release-failed","failure":"Check approved release, explicit absolute paths..."}`. Straight afterwards, the release assets could be reached from GitHub (302 to release-assets, then 200).

  Cause, from the code: `server/scripts/fleet-artifacts.mjs` catches every exception and prints one generic message. The restore makes about 62 GitHub release downloads and doesn't retry any of them, so one transient failure fails the whole build.

  Repair:

  * Retry each download a bounded number of times with backoff, keeping the host allow-list and digest checks.
  * Print the failing step and its error code, but no URLs that carry tokens.

  Acceptance: a test shows one transient failure being retried, and a permanent failure naming its cause.
