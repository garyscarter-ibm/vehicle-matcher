  **Likely cause:** the test connects to `localhost`, which resolves to IPv6 `::1`, while the server it starts listens elsewhere (for example on 127.0.0.1), or it isn't ready yet. Under load, the IPv6 attempt times out before the fallback.

  **Impact:** a red critical path hides real regressions. Every merge today needed reruns to tell this flake apart from a real failure.
