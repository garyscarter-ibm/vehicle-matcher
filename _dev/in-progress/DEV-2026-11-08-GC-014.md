  ## Symptom

  Two leads found this separately on 7 Nov:

  * FUCQ-177 found that, in postgres mode, restarting the backend after a presenter reset fails with "Identity service is unavailable". The cause is a pinned offer-journey policy version that hasn't been adopted yet. Base gcsp-poc does the same.
  * FUCQ-128 found that the plain clock reset doesn't re-adopt the offer-journey policy. FUCQ-128 fixed the related High defect, where adopted policy was copied onto a run that doesn't have it.

  ## Reproduction

  1. Run the demo launcher in postgres mode.
  2. Do a presenter reset.
  3. Stop the backend and start it again.

  ## Expected

  The restart succeeds, and the run's pinned policy versions are all adopted.

  ## Actual

  The restart fails with "Identity service is unavailable".

  ## Impact

  Postgres mode only. The 12 Nov demo runs in memory mode, Gary's fallback after FUCQ-177. So this is below High.
