Through a symlinked path the two differ, so the CLI body never runs and the process exits 0 with no output. The same check is in scripts/gcsp/demo-enrichment.mjs, scripts/gcsp/demo-selection.mjs and server/scripts/prepare-fleet-build.mjs. scripts/gcsp-comparison.mjs already uses the safe realpath form.
