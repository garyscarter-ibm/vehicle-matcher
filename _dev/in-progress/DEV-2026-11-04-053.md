goal: As the presenter, I want every committed offer notification turned into a message I can see, so that the demo shows the email reliably whether or not real mail is set up.
acceptance:
- [x] **Transport port:** a `MailTransport` port with a captured transport. The captured transport stores each rendered message per run: the fictional recipient, subject, plain-text and HTML bodies, the offer link and the demo-clock time. It is the default.
- [x] **Dispatcher:** `dispatchPending()` processes pending outbox jobs. It runs after each committing transaction and at startup, and is registered as a FUCQ-85 tick handler once that registry exists.
- [x] **Idempotent per job:** a retry never sends twice. A failure records the attempt count, the error and the next retry time, and the job stays visible as failed or retrying.
- [x] **Offer message:** an offer notification template renders from the offer and its link. The HTML email contains no script, and there is a plain-text alternative. Copy has no em dashes (house style).
- [x] **Failures never move stock:** dispatch never acquires a car, releases a hold or changes priority. When mail fails, the offer stays visible in the employee's account.
- [x] **Run-scoped:** jobs belonging to an earlier run are not dispatched after a reset; they are marked stale.
- [x] **No token leaks:** the offer token in the link is never written to logs.
