## Static assembly and blueprint checkpoint

Assembly places the output under `/gcsp/`, validates the base path, initial/lazy scripts, stylesheet, packaged font and logo dependencies, and records SHA-256 identities for compiled inputs, compiler package/lock/build settings and output files. Required source revision and observed Node/npm versions accompany that manifest; the manifest alone does not prove compiler execution. Nonempty or symlink outputs and incompatible/unhashed inputs fail. All compiled assets retain their exact bytes; only HTML gets an early configuration-specific CSP meta element and the public runtime JSON is added.
